THE IDEA

Generalize the decision loop.
Keep execution grounded.

The model handles interpretation and candidate generation. Jev compares those candidates, including alternative routes for the same intent. The runtime constrains scope, executes the selected route, then checks the changed application state.

Structured observations are the reliable path today. Screenshot/VLM grounding is available experimentally, but visual-click success across varied applications has not yet been established.

Action mix counts committed actions by execution channel. “Jev calls” counts policy decisions; “model calls” counts planner requests, with VLM calls shown separately.
