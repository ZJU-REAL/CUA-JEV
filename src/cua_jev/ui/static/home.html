: Jev for computer use

One computer-use loop.
Many ways to act.

A text model proposes grounded actions; adapters expand them into legal GUI, DOM, UIA, COM, CLI, MCP and file-API candidates. Jev picks the action and its route, then a guard and an independent verifier close the loop.

Watch recordings How it works Code ↗

Same intent, several routes.

Opening a page, writing a file or running a check can go through the mouse and keyboard, or through DOM, UI Automation, COM, CLI, MCP or a file API.

CUA-JEV turns this into constrained action selection: adapters offer only routes that are legal right now, and Jev's typed choice API picks one. Guards and verifiers stay in deterministic code.
